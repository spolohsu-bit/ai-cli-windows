AI 命令列工具安裝（學校 Windows 版）

中華大學・商業數據分析／Python實用應用專題

步驟 0：確認電腦版本

  1. 按 Win + R，輸入 winver，版本號要 1809 以上。
  2. 開 PowerShell，輸入下面這行。顯示 5.1 的話，照步驟 1 更新。
$PSVersionTable.PSVersion

步驟 1：更新 PowerShell 到 7

舊的 PowerShell 5.1 在舊電腦上下載檔案常失敗（錯誤訊息是 Could not create SSL/TLS secure channel）。PowerShell 7 沒有這個問題。

  1. 下載安裝檔（不經過 Microsoft Store）：
    PowerShell-7.6.6-win-x64.msi
  2. 安裝時一路按「下一步」。
  3. 從開始選單打開「PowerShell 7」（黑色圖示）。以下步驟都在這個視窗裡做。
  4. 先執行一次這行，允許執行腳本。跳出問題時輸入 Y。
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

步驟 2：AntigravityGoogle 帳號

irm https://antigravity.google/cli/install.ps1 | iex

裝完關掉視窗、重開 PowerShell 7，輸入 agy。第一次會開瀏覽器，用 Google 帳號登入。

步驟 3：CodexChatGPT 帳號

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://chatgpt.com/codex/install.ps1 | iex"
  • 整行一起複製。PowerShell 7、舊版 PowerShell、命令提示字元（cmd）都可以貼上執行。
  • 這是命令列版，不經過 Microsoft Store。瀏覽器如果跳出 Store，代表裝到桌面版 App 了，請改用上面的指令。
  • 裝完重開視窗，輸入 codex，用 ChatGPT 帳號登入。

出現 Access is denied 或 daemon 字樣：改用下面這行啟動。

codex --no-daemon

輸入 codex 完全沒反應：電腦缺 VC++ 元件，下載安裝 vc_redist.x64.exe 即可。

步驟 4：OpenCode免費、不用帳號

整段一起複製、貼上執行：

$dir = "$env:LOCALAPPDATA\opencode\bin"
New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://github.com/anomalyco/opencode/releases/latest/download/opencode-windows-x64-baseline.zip -OutFile "$env:TEMP\opencode.zip"
Expand-Archive "$env:TEMP\opencode.zip" -DestinationPath $dir -Force
[Environment]::SetEnvironmentVariable("Path", "$dir;" + [Environment]::GetEnvironmentVariable("Path","User"), "User")
  • 檔案約 180 MB，下載要等一下。
  • 裝完重開視窗，輸入 opencode。進去後輸入 /models，選 Big Pickle 或其他標示 Free 的模型。
免費模型的對話可能被拿去訓練模型，不要貼個人資料。
