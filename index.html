Codex 安裝（學校 Windows 版）

中華大學・商業數據分析／Python實用應用專題

步驟 1：打開 PowerShell

按開始，輸入 PowerShell，打開「Windows PowerShell」。

步驟 2：安裝 CodexChatGPT 帳號

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://chatgpt.com/codex/install.ps1 | iex"
  • 整行一起複製。PowerShell 7、舊版 PowerShell、命令提示字元（cmd）都可以貼上執行。
  • 這是命令列版，不經過 Microsoft Store。瀏覽器如果跳出 Store，代表裝到桌面版 App 了，請改用上面的指令。
  • 裝完重開視窗，輸入 codex，用 ChatGPT 帳號登入。

出現 Access is denied 或 daemon 字樣：改用下面這行啟動。

codex --no-daemon

輸入 codex 完全沒反應：電腦缺 VC++ 元件，下載安裝 vc_redist.x64.exe 即可。

常見問題

看到的訊息處理方式
