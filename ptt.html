安裝說明・練習一：網頁版 2048・練習二：PTT 爬蟲

練習二：叫 AI CLI 寫 PTT 爬蟲

這次 AI 不只寫程式，還會自己安裝套件、自己執行、看到錯誤自己修。你負責說清楚要什麼，然後檢查結果對不對。

0. 準備

mkdir $HOME\Desktop\ptt
cd $HOME\Desktop\ptt

輸入 codex 啟動。

電腦要先裝好 Python。AI 說找不到 Python 的話，到 python.org 下載安裝，安裝畫面第一頁要勾 Add python.exe to PATH。

關卡 1：抓一頁

寫一支 Python 程式 ptt.py，抓 PTT 電影版 https://www.ptt.cc/bbs/movie/index.html 這一頁每篇文章的標題、推文數、作者、日期，印在畫面上。需要的套件請幫我安裝，寫完直接執行給我看。

用瀏覽器打開同一個網址，對照 AI 抓到的標題對不對。

關卡 2：往前翻頁、存成 Excel 打得開的檔案

改成從最新一頁往前抓 5 頁，每抓一頁暫停 1 秒。結果存成 movie.csv，要能用 Excel 直接打開、中文不會變亂碼。

用 Excel 打開 movie.csv，檢查有沒有亂碼、筆數對不對。

不要一次抓幾百頁。抓太快、太多會被 PTT 擋。

關卡 3：分析並畫圖

寫 analyze.py 讀 movie.csv，算出標題裡 [好雷]、[普雷]、[負雷]、[新聞]、[請益] 各有幾篇，畫成長條圖存成 chart.png，然後打開圖片給我看。

如果圖上的中文變成一格一格的方框，不要自己查。直接跟 AI 說：

圖上的中文變成方框了，請修好。

看它怎麼找出原因、怎麼修。

關卡 4：換一個看板

把 ptt.py 改成可以指定看板和頁數，例如 python ptt.py Stock 3 就是抓股票版 3 頁。

挑一個你有興趣的看板（Baseball、NBA、Tech_Job、Food……），抓下來之後，請 AI 幫你從資料裡找出一個有趣的發現。
